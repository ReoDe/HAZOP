# UI/UX 디테일 개선 명세 (2026-11-07)

[README](README.md) · [결함 목록](defect-list.md) · [조사 요약](survey-summary.md) · 시안 `index.html`, `png/`

## 기준

- 2026-11-07 결정(B안 고밀도 작업대 + A안 단계 표시)을 그대로 둔다. 시안 `build.py`는 `hazop/app/tokens.py` COLORS를 직접 읽는다. 다만 어두운 제목줄·상태 표시줄·토스트 위 보조색(명령 상자 바탕, 완료 ✓·실패 글자, 토스트 링크 등 약 17개)은 COLORS에 없어 `build.py`에 hex로 적었다. 구현할 때 이 색을 토큰으로 추가하고 대비를 검사해야 한다.
- 도면 캔버스는 흰 바탕을 유지한다.
- 셸은 옵시디언 방식으로 바꾼다. 구성은 왼쪽 레일(단계) + 탐색기, 가운데 탭, 위쪽 명령 찾기, 오른쪽 관련 항목 패널, 아래 상태 표시줄이다.
- 우선순위: **필수**는 잘못된 판정·작업 차단 결함을 고치거나 셸의 뼈대가 되는 항목, **권장**은 반복 작업을 줄이는 항목, **나중**은 다듬기다.
- 난이도는 [추론]이다. **하**는 반나절 이하이고 기존 위젯 안에서 끝난다. **중**은 1~2일이며 새 위젯이나 데이터 연결이 필요하다. **상**은 3일 이상이며 화면 구조를 바꾼다.
- "건드리는 파일"은 구현 배정 때 다른 세션과 겹치는지 보기 위한 값이다. ② 수동 수정 세션은 `viewer`·`corrections`, 4단계 세션은 `study/*`·⑤ 화면을 쓰고 있다.

## 셸 사양

| 영역 | 크기 | 내용 |
| --- | --- | --- |
| 제목줄 | 높이 32px, `nav-bg` | 왼쪽 앱 이름·메뉴, 가운데 명령 찾기 상자(누르면 팔레트, `Ctrl+P` 표시), 오른쪽 검토자 이름 한 번 |
| 레일 | 폭 48px | 단계 ①~⑤ 원 번호. 완료는 초록 채움 + 오른쪽 위 ✓, 현재는 밝은 배경. 번호는 항상 보인다 |
| 탐색기 | `clamp(200px, 14vw, 260px)`, 끌어서 조절 | 필터 상자, 그룹(자료·지식그래프·검토구간·권고)마다 개수, 구간은 색 점과 미검토 수, 현재 탭의 대상은 왼쪽 파랑 선으로 강조 |
| 탭 줄 | 높이 32px | 도면·구간·결과·그래프 탭. 저장 안 된 탭은 점, 나머지는 ✕. 오른쪽 끝 "분할" |
| 관련 항목 | `clamp(264px, 20vw, 340px)`, `Ctrl+Alt+B`로 접기 | 현재 선택(칸·구성요소·자료)의 도면 위치, 구성요소, 지식그래프 근거, 같은 구성요소를 쓰는 다른 칸, 변경 이력. 섹션마다 접기와 개수 |
| 상태 표시줄 | 높이 24px | 왼쪽은 현재 도면과 개수, 오른쪽은 저장 상태·진행·단축키 안내. 값이 없는 항목은 숨긴다 |

1366×768에서 가운데 영역은 약 845px이다(1366 − 48 − 200 − 273). 1920×1080에서는 약 1,272px이다(1920 − 48 − 260 − 340).
