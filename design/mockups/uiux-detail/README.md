## 알아 둘 점

- 시안은 구현물이 아닙니다. 데이터는 가상 표본(SNP-M-102)이고 실제 설계값이 아닙니다.
- 앱 코드(`hazop/`, `scripts/`, `tests/`)는 고치지 않았습니다. 같은 폴더에서 다른 두 세션이 작업 중이기 때문입니다.
- 예상 작업량과 Qt 난이도는 [추론]입니다. 실제 구현 전에 담당이 다시 산정해야 합니다.
- 시안의 표본 데이터는 화면끼리 완전히 맞추지 않았습니다. 시안 2·5의 탐색기는 확정 구간 5개를 보여 주지만 본문은 제안 10개입니다. 시안 2의 행별 "확정/제안"도 실제 규격(구간 집합 단위 확정)과 다릅니다. 배치와 상호작용만 참고해 주세요.
- 시안의 열 수 계산은 HTML 폭 기준입니다. Qt로 옮기면 여백과 스크롤 막대 때문에 1~2열 줄 수 있습니다.

## 직접 확인할 부분

1. 시안 1(⑤)의 행렬 위·워크시트 아래 배치가 실제 검토 방식에 맞는지 확인해 주세요. 워크시트를 더 크게 봐야 하면 위아래 비율을 바꿀 수 있습니다.
2. 단축키 한 글자(A 승인, R 기각, J 다음 미검토)가 실수로 눌릴 위험이 있습니다. 확정이 아니라 상태 변경이고 실행 취소가 있지만, 승인에 확인 단계를 둘지 정해 주세요.
3. ⑤ 화면은 4단계 세션이 남긴 스크린샷(SNP-M-102, AI 실행 후)으로 점검했습니다. 그 세션이 끝난 뒤 다시 찍어 결함이 그대로인지 확인해야 합니다.
4. HAZOP 소프트웨어 조사는 공개 자료만 봤습니다. PHA-Pro 화면은 컨설팅사 템플릿이라 기본값과 다를 수 있습니다.
