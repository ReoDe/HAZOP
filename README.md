# HAZOP

설계도면과 문서에서 설비·연결 관계·운전조건 등을 추출하여 통합 그래프로 관리하고, 그래프 알고리즘과 AI 탐색을 통해 전문가 검토용 HAZOP 분석 초안을 생성하는 프로젝트입니다.

현재는 전체 워크플로우와 단계별 요구사항을 정리하는 기획 단계입니다. 아래 기능은 개발 방향이며, 구현 완료를 의미하지 않습니다.

## 전체 기획과 워크플로우

- [전체 기획](기획서/전체기획.md): 목적, 범위, 공통 원칙과 첫 개발 목표
- [최상위 플로우차트](<flow chart/00-overview.md>): 전체 흐름과 단계별 상세 기획의 진입점

전체 흐름은 **자료 등록 → 정보 추출 → 정보 통합·관리 → HAZOP 분석 → 검토·결과 관리**로 구성합니다. 각 단계의 상세 플로우차트와 기획서는 논의하면서 순차적으로 작성합니다.

## 프로젝트 방향

1. **자료별로 추출 방법을 나눕니다.** P&ID·PFD 등의 도면, 표·사양서, 글로 작성된 보고서에 맞는 변환 스크립트를 구성합니다.
2. **추출 결과는 공통 구조로 통합합니다.** 설비·배관·물질·운전조건·보호수단 등을 관리하고, 태그와 라인 번호 등을 이용해 자료 사이의 동일 대상을 연결합니다.
3. **모든 정보에 원문 근거를 남깁니다.** 파일, 버전, 페이지, 도면 위치나 문장을 추적하고, 미확인 정보와 자료 간 충돌을 표시합니다.
4. **사람이 검증하고 수정할 수 있게 합니다.** 원본 도면과 그래프를 대조하고 연결 관계와 추출 내용을 확정합니다.
5. **검증된 정보를 HAZOP 분석에 활용합니다.** 검토 구간과 운전모드를 정의하고, 편차별 원인·영향 경로와 보호수단을 검토하여 초안을 만듭니다.

Markdown·위키는 기획과 정보 열람에 활용합니다. 설계정보의 값·단위·관계·적용 조건은 구조화하여 관리하며, 구체적인 저장 기술은 상세 기획에서 결정합니다.

## 대상 설계자료

| 자료 | 활용 방향 |
| --- | --- |
| 공정 설계 의도 및 설명서 | 공정 목적, 설비 역할, 분석 범위 정의 |
| PFD 및 물질·열수지 | 공정 흐름과 물질·에너지 정보 연결 |
| P&ID | 설비·배관·계기 및 연결 관계 추출 |
| 물성·위험성 자료 | 물질 특성과 위험성 연결 |
| 운전조건 및 허용 한계 | 정상 조건과 운전·설계 한계 연결 |
| 주요 기기·배관 설계 사양 | 용량·재질·등급 등의 속성 연결 |
| 제어·경보·인터록 설계 | 감지·제어·차단 조건과 동작 연결 |
| 압력 방출 및 비상 배출 설계 | 보호 대상과 방출 경로 연결 |
| 운전모드 및 주요 운전 절차 | 모드별 조건과 작업 절차 연결 |
| 유틸리티 및 외부 연결 조건 | 공급 의존 관계와 외부 설비 연계 |

자료는 확보되는 순서대로 반영합니다. HAZOP 분석에 필요한 정보가 부족하면 미확인 사항으로 남깁니다.

## 첫 개발 목표

**P&ID 한 장의 작은 구간을 검증 가능한 연결 그래프로 변환하는 편집기**를 우선 개발합니다.

- 기호·태그·배관을 추출하여 연결 그래프 초안 생성
- 원본 도면과 그래프를 대조하며 누락·오인식·연결 오류 수정
- 확정한 노드와 관계를 원본 근거와 함께 저장

이후 운전조건 문서 등에서 같은 설비의 정보를 추출해 연결하고, 여러 도면과 문서로 범위를 확장합니다.
