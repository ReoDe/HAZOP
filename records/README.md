# 메모리 운영

[프로젝트 소개](../README.md)

대화에서 정한 결정과 미구현 작업을 이 폴더에 기록합니다. 장기적인 설계 설명은 README와 기획서에 두고, 이 폴더에는 결정의 이력과 남은 작업만 둡니다.

| 파일 | 내용 | 운영 규칙 |
| --- | --- | --- |
| [결정로그.md](결정로그.md) | 날짜·결정 내용·결정 주체·근거와 관련 문서 | 삭제하지 않고 누적. 결정이 바뀌면 새 항목을 추가하고 이전 항목에 대체 사실을 표시 |
| [남은작업.md](남은작업.md) | 구현·확인·결정이 남은 작업 | 구현과 검증이 확인되면 해당 항목 삭제. 여러 부분으로 된 항목은 완료된 부분만 삭제 |

- 작업을 시작하거나 이어갈 때 두 파일을 먼저 확인합니다.
- 기획서 작성만으로 구현 완료로 보지 않습니다.
- 결정 주체는 "사용자"(사용자가 직접 정함), "권고 승인"(Claude의 권고를 사용자가 승인), "제안"(아직 승인되지 않음)으로 구분합니다.
