# 메모리 운영

[프로젝트 소개](../README.md)

대화 중 이후 작업에서 기억해야 할 결정과 미구현 요구사항을 이 폴더에 누적합니다. 대화 전체를 복사하기보다 작업에 필요한 내용과 관련 기획 문서를 남깁니다.

- 작업을 시작하거나 이어갈 때 이 폴더의 내용을 확인합니다.
- 기억할 내용이 생기면 해당 주제 파일에 추가하거나 새 파일을 만듭니다.
- 기획서 작성만으로 구현 완료로 보지 않습니다.
- 구현과 관련 검증이 확인되면 해당 항목을 삭제합니다. 주제 파일이 비면 파일도 삭제합니다.
- 여러 부분으로 구성된 항목은 완료된 부분만 삭제하고 남은 요구사항을 유지합니다.
- 장기적인 설계 설명은 README와 기획서에 유지하고, 메모리에는 남은 작업을 둡니다. 이 운영 안내는 유지합니다.
