# 자동 처리·수동 편집·독립 검증

기록일: 2026-11-02. 현재는 기획 초안만 작성되었으며 아래 기능은 미구현입니다. 구현·검증된 항목만 삭제합니다.

- 자료 등록·정보 추출·정보 통합은 Python 스크립트로 자동 처리한다. 자료 종류별 스크립트의 결과는 공통 형식으로 모은다.
- AI의 주 용도는 HAZOP 단계에서 추출 노드와 그래프 알고리즘의 탐색 결과를 바탕으로 추론·답변하는 것이다.
- 앞 단계에서 결과가 불만족스러우면 AI로 원문 대조와 최종 검수·보정 제안을 할 수 있다. AI 보정도 검증을 우회하지 않는다.
- 사람은 노드·사실을 수동 추가·수정하고 관계를 연결·해제할 수 있어야 한다. 변경 이력과 근거를 남긴다.
- 각 상세 흐름에는 독립적인 입력·출력·검증 사례·통과/보류 기준이 있어야 한다. 다른 단계와 AI 없이 샘플 입력으로 검증 가능해야 한다.
- 도면과 문서에서 같은 대상을 연결하되 원문·버전과 충돌 정보를 유지하고, 수동 수정을 자동 재처리가 덮어쓰지 않게 한다.
- 설계자료 10종을 등록하고 도면·표·설명문별로 추출한다. 정보 통합의 직접 입력은 추출 결과와 수동 입력이며, 원본은 근거로 연결한다.
- 노드·관계·속성의 정의를 점진적으로 관리한다. 현재 기획서의 초안을 향후 데이터 사전과 기계 판독용 정의로 연결하고, Python에서 자료형·단위·필수 여부·허용값과 관계 제약을 검증한다. 개별 사실·관계의 출처와 버전도 유지한다.
- 실제 입력 순서에 맞춰 자료 등록부터 기획·구현하고 정보 추출, 원본 대조·수정, 통합으로 진행한다. 첫 등록 대상은 사용자 변경 결정에 따라 FreeCAD(.FCStd) 또는 draw.io(.drawio)로 직접 만든 원본이다. PDF·PNG·JPG는 후속 지원 대상으로 옮긴다. 원본 보존·식별정보·중복/개정 충돌·저장 무결성을 독립 검증한다. 관련 초안: [자료 등록 기획](../기획서/자료등록.md).
- 첫 자료 등록 화면은 웹으로 만들고 파일 선택과 드래그 앤 드롭을 모두 지원한다(사용자 결정). 두 입력 방식에 동일한 Python 검증을 적용한다.
- 정보 추출은 P&ID 페이지 전체 추출과 선택 구간 재처리를 모두 지원한다(사용자 결정). 수동 보정·범위 밖 결과를 보존하고 경계 연결과 중복을 검증한다. 관련 초안: [정보 추출 기획](../기획서/정보추출.md).
- P&ID 기호의 의미·포트·선 종류·교차/분기·태그 및 외부 연결 규칙을 근거·적용 범위·버전과 함께 축적한다. 프로젝트 고유 범례를 구분하고, 실제 샘플에서 인식 방법을 검증한다. Python으로 구현한다는 사실만으로 도면 이해가 해결된 것으로 보지 않는다.
- P&ID의 다양한 자료형(벡터·스캔·혼합 PDF, 이미지, CAD 원본, 구조화된 설계 데이터)을 장기적으로 모두 고려한다. 다양한 자료형 고려는 글로 기록하며, 첫 대상은 FreeCAD·draw.io 원본으로 변경한다. 추가 형식은 지원 우선순위와 처리·검증 방법을 추후 정한다.
- 첫 추출은 원본 객체·속성·커넥터를 읽는 Python 어댑터를 우선 검토한다. draw.io의 명시적 연결과 단순 선, FreeCAD의 형상 연결과 공정 연결을 구분한다. 실제 제공 샘플로 첫 구현 도구와 속성·포트 규칙을 정한다.
- 구현 전에 00-오버뷰의 전체 단계 플로우차트와 기획서를 먼저 작성한다. 현재 ①~⑤ 초안을 작성했으나 기능은 미구현이다. 단계 사이 입력·출력·상태·버전을 점검하고 실제 구현은 자료 등록부터 진행한다.
- ④ HAZOP 분석의 첫 범위는 사람이 선택한 구간의 정상 운전이다. 전체 편차 후보의 선택·제외·보류와 이유를 DB 형태로 누적하고, 제외 후보도 화면 재조회·재검토할 수 있게 한다.
- 알고리즘이 경로·설계 근거를 찾고 AI가 해석·추가 가설을 제시한다. 연결 경로와 인과관계, 확인된 사실과 가설을 구분한다. 정보가 부족하면 가능 범위만 분석하고 나머지는 보류·자료 요청을 남긴다.
- ④에서 AI가 위험도를 제안하고 ⑤에서 사람이 확정한다(사용자 결정). 평가 기준·버전·근거·가정을 기록하고, 기준·근거가 없으면 제안을 보류한다. AI 제안과 확정값은 분리한다. 관련 초안: [HAZOP 분석 기획](../기획서/HAZOP분석.md).
- ⑤는 편차 목록에서 선택하면 도면·경로·근거·AI 제안을 함께 보여주고, 사람이 편차별 원인·결과·보호수단·위험도를 수정·최종 확정한다(사용자 결정). AI 원안과 변경 이유·확정 이력을 보존한다.
- 개선 권고만 조치로 관리하고 자료 요청은 편차에 연결된 메모로 남긴다(사용자 결정). 메모 작성이나 조치 완료로 검토 확정·보류 해제를 자동 처리하지 않는다.
- 관련 도면·운전조건·그래프가 바뀌면 해당 검토 구간의 모든 편차를 재검토 대상으로 표시한다(사용자 결정). 선택·제외·보류를 포함하며 과거 확정본과 당시 버전을 보존한다.
- ⑤ 첫 출력은 화면 재조회와 Excel 워크시트 내보내기다(사용자 결정). 초안·보류·확정·재검토 상태와 출력 버전을 보존한다. 관련 초안: [검토·결과 관리 기획](../기획서/검토결과관리.md).
