## 사용자 제공 대기

- draw.io로 작성한 소규모 샘플 P&ID. 받으면 [작성 규칙](../기획서/정보추출.md#drawio-rules)과 [최소 그래프 정의](../기획서/정보통합관리.md#definitions)를 확정합니다.
- AI·분석 품질 평가 기준(편차별 정답 원인·결과·보호수단 등). 받으면 [품질 평가](../기획서/HAZOP분석.md) 방법을 확정합니다.

## MVP 수직 슬라이스 구현

- ① 폴더·스크립트 기반 등록: 형식 확인, 해시, 내부 ID·등록 버전, 동일 원본 재사용, 저장 후 해시 확인과 MVP 검증 사례
- ② draw.io 읽기 어댑터(일반·압축 저장)와 추출 결과 JSON·검증 보고서
- ③ 도면 1장의 그래프 변환, 최소 정의에 따른 구조 검증, 그래프 버전·대상 매핑 저장
- ④ 구간 지정 JSON, 소수 편차 규칙, 소규모 원인·결과 패턴, 제한된 그래프 탐색, Claude 모델 호출(호출부 분리), 결과 JSON
- ⑤ Excel 워크시트 출력(분석 정보·전체 후보·HAZOP 워크시트)과 평가 기준 비교
- 단계 사이 ID·버전·검증 상태·확인 수준이 [데이터 규격](../기획서/전체기획.md#data-contract)대로 이어지는지 확인

## 구현 전 결정

- 구독 중인 Claude 모델을 애플리케이션에서 직접 쓸 수 있는지 확인(API 과금 체계와 구분)
- PSA 초기사건 후보 표시 기준·필드, 초기사건 그룹화, 위험도 제안 기능의 유지 여부 ([미결정 사항](../기획서/HAZOP분석.md#psa))
- 초기사건 등 원자력 용어의 정의 원문 확인과 인용(NRC·ASME/ANS PRA 표준)
- DEXPI 클래스 체계를 참고할 범위
- 실제 발전소 도면 사용 전 데이터 반출 정책과 로컬 LLM 전환 여부
- 샘플 도면을 저장소에 둘지 여부

## 디자인

- `디자인/` 폴더에 실제 사용 시 화면·구성·사용 흐름의 뼈대 작성. 범위와 형식은 사용자와 논의 후 결정

## 후속 기능 (MVP 검증 후)

- 웹 등록 화면(파일 선택·드래그 앤 드롭), 개정 충돌 판정, 메타데이터 수정 이력
- 선택 구간 재처리, 웹 원본 대조·수동 편집, AI 보정 제안
- 실제 자료형(PDF·이미지·CAD 등) 읽기 어댑터
- 여러 도면·문서의 동일 대상 통합과 값 충돌 관리
- 후보 판단 화면, 자동 구간 분할, 기동·정지 모드
- ⑤ 검토 화면, 편차별 확정·이력, 개선 조치·자료 요청 메모, 변경 알림과 구간 전체 재검토(영향 없음 판정 포함)
