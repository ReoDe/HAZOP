## PDF 등록 후속(2026-11-07 PDF 보완 후 남은 것)

- PDF 배관에 흐름 방향이 없어 ②에서 공정 배관이 '미확인 항목 있음' 점선으로 보임(근사 경로는 0). 화살촉을 흐름 방향 근거로 쓸지 결정 필요
- 계기 태그 접두는 같은 쪽 다수 접두를 추정한 값([추론]). 계통 경계 계기는 틀릴 수 있음. 501처럼 접두가 동률이면 비워 둠. 분기점·끝막음은 보이는 글자가 없어 태그 없음
- 여러 쪽 PDF를 한 번 등록하면 모든 쪽이 같은 도면번호·제목을 씀(등록 1건 = 도면 1장 전제). 쪽별 식별정보 필요 여부 결정
- 첫 쪽이 빈 PDF는 등록 단계(표제란 후보)에서 막힘
- 정렬 측정은 같은 PDF를 두 번 읽은 값(그림 vs 추출)의 대조이며 독립 정답 비교가 아님. ① 화면에는 '확인됨'만 표시
- 미등록 CLI 출력 폴더 이름: 도면번호가 `X-p1`인 0쪽과 `X`인 1쪽이 같은 폴더가 됨(Codex 경미 판정). 예외로 끝난 쪽은 파일 이름 기준 폴더
- 점선 신호선 경로는 점선 조각 중심을 이은 선이라 양 끝이 조각 길이 절반만큼 짧음
- 1쪽 PDF가 미추출이면 ① 목록에 '없음'만 나오고 사유는 결과 메시지에만 나옴
- 실제 Windows 앱에서 큰 PDF 미리보기 멈춤 여부는 offscreen 테스트로만 확인

## ⑤ Excel 내보내기 후속(2026-11-08 검토 경미 지적)

- 분석 전 칸에서 AI 실행이 실패하면 워크시트에는 '실패' 행이 생기는데 표지의 '분석 전 칸(워크시트에 행 없음)'에도 함께 셈
- '승인만' 범위에서도 표지 '시나리오 수'는 모든 상태를 셈(워크시트 행 수는 따로 적음). 범위별 표기 정리 필요 여부
- 이력 시각이 `YYYY-MM-DDTHH:MM:SSZ` 형식이 아니면 내보내기 전체가 실패함(데이터 손상은 없음)
- 저장 대화상자 밖에서 `.xlsx`를 붙인 이름은 덮어쓰기 확인을 거치지 않음(Windows 기본 대화상자가 확장자를 붙이는지는 미확인)
- 실제 Excel에서 열어 인쇄 미리보기(가로·머리행 반복)를 눈으로 본 적 없음(openpyxl 속성만 검사)
- 사용자 시나리오 S12의 저장 대화상자 기본 파일 이름은 UIA로 읽지 못해 스크린샷 확인만 함

## 3단계(검토구간·결과 셸) 후속

- 샘플에서 펌프·오리피스·필터가 모두 equipment라 각자 구간이 됨(SNP-M-201 구간 18개). 배관 중간 요소를 공정 요소로 볼지 사용자 결정 필요
- 구간당 밸브·펌프 5개 분할 규칙은 샘플에서 작동한 적 없음(합성 테스트로만 확인)
- 같은 구간 파일을 두 창에서 편집하면 나중 저장이 덮어씀(저장 전 디스크 판 비교 없음)
- 저장본을 읽지 못하면 새 제안이 묻지 않고 덮어씀(백업 없음)
- nodes.load가 graph_id 일치를 확인하지 않음(safe_name 충돌 시 다른 도면 구간 로드 가능)
- 병합 뒤 _next_id가 사라진 최대 번호를 재사용(이력에서 같은 S번호가 두 구간)
- ④ 구성요소 표시 라벨이 HTML로 해석될 수 있음(표시 왜곡만)
- ⑤ '권고' 탐색기 그룹 비어 있음(위험도 열·결과 저장은 4단계에서 구현)
- ⑤ 설계의도는 같은 그래프를 가리키고 구간 구성요소를 모두 포함하는 데이터/구간 파일에서만 가져옴(그 외 '설계의도 미입력')
- 배포본 verify_bundle --app-only가 찍는 앱 스크린샷은 ①②와 이전 ④⑤ 4장뿐(새 ④⑤ 미포함)

## 4단계(AI 분석) 후속

- 실제 API 실행 확인은 사용자가 키를 넣고 직접 한다(헤더·fallbacks 수용 여부, 대체 모델의 구조화 출력 준수, 실제 비용)
- 근거 검증은 도면 전체와 대조한다. 구간 맥락 밖(다른 구간) 태그 인용은 경고하지 않는다(Codex 지적, 경미)
- 매트릭스의 '실패' 칸이 위험 5와 같은 색이다(글자로만 구분)
- 창을 닫을 때 진행 중인 호출을 최대 600초까지 안내 없이 기다린다
- validate가 저장된 risk와 강도×빈도 표 조회 값의 일치를 검사하지 않는다
- 위험도 툴팁 "강도 × 발생빈도"는 곱셈처럼 읽힌다(실제로는 표 조회)
- 1920 폭에서 행렬 영역이 좁다(분할선 기본 비율 조정 필요)
- 스크린샷 스크립트의 '분석 전' 화면 상태줄에 이전 실행 문구가 남는다
- 인터페이스 기획서 §8의 '네트워크 없음' 규칙 문구를 4단계 예외(claude_http)에 맞게 고쳐야 한다
- 배포본 verify_bundle --app-only 스크린샷에 새 ⑤ 화면이 없다

## ② 도면 사람 수정 후속

- 수정한 도면은 단계 연쇄 검사(check_contract X2·K1·K2)가 원본으로 다시 계산해 판이 달라짐. 그래프에 수정 기록 적용 출처 표시 필요(Claude 검토, 경미)
- 수정 기록을 추출 폴더 이름으로만 찾아 `출력/samples/추출/<같은 이름>`에도 적용될 수 있음(QA 회귀 오염 가능)
- 새 등록 버전(<자료 ID>-r<버전>)은 폴더 이름이 바뀌어 수정 기록 없이 시작함. 이전 판 수정을 옮겨 올지 결정 필요
- 이동 확인 창에서 '저장'을 고르면 다시 그리기 콜백이 다음 화면(④)의 웹뷰를 가져갈 수 있음(재현 안 함)
