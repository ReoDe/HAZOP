# docs/governance — 운영 문서

저장소를 운영하는 규칙(이름, 보관 위치, 문서 상태)을 둔다.

## 무엇을 넣는가

- 이름 규칙과 이전 계획: `naming-rules/` (HZ-GOV-02)

## 넣지 않는 것

- 제품 규격은 `docs/specs/`, 작업 단위 기록은 `docs/units/`에 둔다.
- 모델 배정표 같은 총괄 운영 규칙은 `CLAUDE.md`에 있다.

## 이름 형식

`<주제>/README.md`가 본문이고 근거는 `<주제>/evidence/`, 대응표 같은 데이터는 같은 폴더에 둔다.

## 주인

총괄. 규칙을 바꾸면 문서의 `rev`를 올리고, `approved`는 총괄만 바꾼다.

## 폐기 기준

지우지 않는다. 쓰지 않게 된 문서는 `status: obsolete`로 두고, 문서번호는 다시 쓰지 않는다(HZ-GOV-02 §4.6, §4.12).
