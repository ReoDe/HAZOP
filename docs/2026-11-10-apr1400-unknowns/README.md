## 2. 근본 원인과 단위

### 3a. 신호선 빗금(//)이 배관 가지가 됨

APR1400은 공압 신호선을 실선 위 빗금 두 줄(//)로 그린다(범례 1.7-1 4/4). 빗금 한 줄은 1~2pt라 끝이 선 끝 맞춤 허용 오차(1.5pt) 안에 들어온다. 그래서 추출기가 빗금마다 배관 분기점을 만들고, 빗금과 그 사이 토막을 같은 분기점으로 돌아오는 자기 고리 조각으로 만들었다. 계기 공기선 자체도 공정 배관(`physical_connection`)으로 남았다.

고친 것은 다음과 같다.
- **빗금 판정.** 4pt 이하 직선 조각이 10pt 이상 열린 선을 비스듬히(30~80°) 실제로 가로질러야 한다. 두 끝이 선의 양쪽에 떨어져 있어야 하므로, 한 끝만 닿은 탭은 빗금이 아니다. 빗금은 가장 가까운 선 하나에만 딸린다. 평행하고 가까운 빗금 2~3개가 묶음 하나이고, 묶음이 둘 이상인 선만 신호선 후보다.
- **빗금 빼기.** 빗금은 기호 묶기가 끝난 뒤 남은 선에서만 뺀다. 기호 장식선으로 흡수된 빗금은 그대로 두므로, 143쪽 모든 기호 노드의 id·kind·위치가 바뀌기 전과 같다. 뺀 빗금은 `ignored_objects`(`line_tick`)에 남긴다.
- **공압 신호선 표시.** 빗금 선으로만 되고 그 사슬 위에 빗금 묶음이 실제로 있는 사슬만 `signal_connection`(`pdf_pneumatic`)이다. 배관과 섞이거나 빗금 없는 쪽 토막이면 배관으로 둔다.
- **분기점 태그.** 계산으로 만든 분기점은 태그가 있을 수 없으므로 `missing_tag`를 남기지 않는다.
- **사람 수정 보존(D14).** 빗금 조각이 빠지면 연결·분기점 번호가 밀린다. 그래서 수정 적용 때 대상 id가 없거나 지문이 다르면, 같은 위치·같은 종류의 대상이 정확히 하나일 때 그 대상에 적용하고 `corrections.retargeted`에 남긴다(`hazop/extract/corrections.py`). 117~125쪽에서 이전 추출로 만든 수정을 새 추출에 대 보니, 살아남은 대상 2,716개 중 2,689개(99%)에 적용됐다. 다른 자리에 들어간 것은 0개다. 남은 27개는 같은 자리 후보가 없거나 둘 이상이라 일부러 적용하지 않았다.

결과는 다음과 같다.
- 미확인 99,308 → 74,974(−24.5%). 자기 고리 12,203 → 6,251, 태그 없음 23,078 → 11,963, 흐름 방향 39,207 → 31,940. 120쪽은 3,111 → 537.
- 태그 정확 781, 연결 표기 284/293, 짝 234, 틀린 대상·틀린 짝 0(후퇴 없음).
- SNP 노드·관계 동일. 분기점 태그 없음 미확인만 6개 도면에서 줄었다.
- 검토(적대 2, Codex 1)에서 바꾼 것: 가로지르지 않는 탭 오인, 한 자리에 몰린 빗금을 묶음 둘로 셈, 나뉜 경로 전파, 빗금을 기호 묶기 전에 빼서 응축기·구동 밸브가 안전밸브로 바뀜, 번호 밀림으로 사람 수정이 빠짐.
