## 2. 근본 원인과 단위

### 3a. 신호선 빗금(//)이 배관 가지가 됨

APR1400은 공압 신호선을 실선 위 빗금 두 줄(//)로 그린다(범례 1.7-1 4/4). 빗금 한 줄은 1~2pt라 끝이 선 끝 맞춤 허용 오차(1.5pt) 안에 들어온다. 그래서 추출기가 빗금마다 배관 분기점을 만들고, 빗금과 그 사이 토막을 같은 분기점으로 돌아오는 자기 고리 조각으로 만들었다. 계기 공기선 자체도 공정 배관(`physical_connection`)으로 남았다.

고친 것은 다음과 같다.
- **빗금 판정.** 4pt 이하 직선 조각이 10pt 이상 열린 선을 비스듬히(30~80°) 실제로 가로질러야 한다. 두 끝이 선의 양쪽에 떨어져 있어야 하므로, 한 끝만 닿은 탭은 빗금이 아니다. 빗금은 가장 가까운 선 하나에만 딸린다. 평행하고 가까운 빗금 2~3개가 묶음 하나이고, 묶음이 둘 이상인 선만 신호선 후보다.
- **빗금 빼기.** 빗금은 기호 묶기가 끝난 뒤 남은 선에서만 뺀다. 기호 장식선으로 흡수된 빗금은 그대로 두므로, 143쪽 모든 기호 노드의 id·kind·위치가 바뀌기 전과 같다. 뺀 빗금은 `ignored_objects`(`line_tick`)에 남긴다.
- **공압 신호선 표시.** 빗금 선으로만 되고 그 사슬 위에 빗금 묶음이 실제로 있는 사슬만 `signal_connection`(`pdf_pneumatic`)이다. 배관과 섞이거나 빗금 없는 쪽 토막이면 배관으로 둔다.
- **분기점 태그.** 계산으로 만든 분기점은 태그가 있을 수 없으므로 `missing_tag`를 남기지 않는다.
- **사람 수정 보존(D14).** 빗금 조각이 빠지면 연결·분기점 번호가 밀린다. 그래서 수정 적용 때 대상 id가 없거나 지문이 다르면, 같은 위치·같은 종류의 대상이 정확히 하나일 때 그 대상에 적용하고 `corrections.retargeted`에 남긴다(`hazop/extract/corrections.py`). 117~125쪽에서 이전 추출로 만든 수정을 새 추출에 대 보니, 살아남은 대상 2,716개 중 2,689개(99%)에 적용됐다. 다른 자리에 들어간 것은 0개다. 남은 27개는 같은 자리 후보가 없거나 둘 이상이라 일부러 적용하지 않았다.

결과는 다음과 같다.
- 미확인 99,308 → 74,974(−24.5%). 자기 고리 12,203 → 6,251, 태그 없음 23,078 → 11,963, 흐름 방향 39,207 → 31,940. 120쪽은 3,111 → 537.
- 태그 정확 781, 연결 표기 284/293, 짝 234, 틀린 대상·틀린 짝 0(후퇴 없음).
- SNP 노드·관계 동일. 분기점 태그 없음 미확인만 6개 도면에서 줄었다.
- 검토(적대 2, Codex 1)에서 바꾼 것: 가로지르지 않는 탭 오인, 한 자리에 몰린 빗금을 묶음 둘로 셈, 나뉜 경로 전파, 빗금을 기호 묶기 전에 빼서 응축기·구동 밸브가 안전밸브로 바뀜, 번호 밀림으로 사람 수정이 빠짐.

### 3c. 매설 배관 무늬의 점이 외톨이 신호선 조각이 됨

APR1400은 매설 배관(BURIED PIPE, 범례 1.7-1 1/4)을 선 위에 작은 검은 점을 찍어 그린다(090쪽 소화 본관, 022쪽 등). 점은 긴 변 1.5pt 이하라 추출기가 채운 점선 조각으로 분류했다. 점끼리는 8pt쯤 떨어져 점선 사슬로 이어지지 않으므로, 점마다 양 끝이 빈 점선 신호 조각이 됐다(090쪽 끝점 미연결 1,030개).

고친 것은 다음과 같다.
- **선 위 점.** 꽉 찬(면적이 상자의 절반 이상) 정사각형에 가까운 1.5pt 이하 채운 조각이 실선 위 1pt 안에 있고 같은 선에 2개 이상이면 선 장식이다. 점선 조각에서 빼서 `ignored_objects`(`line_dot`)에 남긴다. 선에서 떨어진 점(열선 추적 표시)과 점선 경로 위 점은 건드리지 않는다.
- **선 종류는 바꾸지 않는다.** 처음 구현은 점이 얹힌 스트로크 점선을 매설 배관(`pdf_buried`)으로 바꿨다. 하지만 검토 결과 143쪽에서 그렇게 바뀐 16개가 모두 분기점 점이 있는 가는 점선 신호선이었다(예: 123쪽 손스위치 → 급수 부스터 펌프). APR1400의 실제 매설 배관은 실선이나 채운 조각으로 그려진다. 그래서 선 종류 변경은 뺐다.
- **끝막음 뒤처리 규칙.** 몸체 안에 원이 든 기호에는 끝막음(`pipe_cap`) 규칙을 쓰지 않는다. HEAD에서 끝막음으로 잘못 정해지던 소화전 13개(090쪽)와 E/H 구동부 원·작은 계기 원이 kind 없음으로 돌아간다.
- **사람 수정(D14).** 같은 자리에서 틀린 kind가 지워진 경우도 같은 대상으로 본다(채워진 경우와 대칭). 088~090·123·022쪽에서 HEAD 추출로 만든 수정이 살아남은 대상 1,765개에 모두 적용됐다.

결과는 다음과 같다.
- 미확인 74,769 → 71,203(−4.8%, U4 뒤 기준값 대비). 끝점 미연결 15,981 → 12,391, kind 없음 8,008 → 7,919.
- 태그 정확 872, 연결 표기 286/295, 짝 257, 틀린 대상·틀린 짝 0(후퇴 없음). SNP 노드·관계 동일.
- 검토(적대 2, Codex 1)에서 바꾼 것: 매설 배관 재분류 제거(16개 모두 오판), 가는 대각 대시를 점으로 오인, 점선 경로 끝 밖의 점, 지워진 kind의 사람 수정 보존.

### 사전 조사 (3a 뒤, 저장소 밖 시험 스크립트)

- **흐름 방향(3b 후보).** 배관 사슬 35,874개 가운데 검은 삼각 화살촉이 실제로 얹힌 사슬은 1,134개(3%)이고, 서로 반대인 사슬이 29개다. 두 포트 기호(밸브·배관 부품)를 지나고, 분기점에서 하나 남은 가지를 정하는 식으로 퍼뜨려 보았다. 그래도 물리 관계 19,745개 중 674개 씨앗이 898개로 늘 뿐이다(kind 없는 두 포트 기호까지 지나면 1,063개). APR1400 공개 도면 배관 대부분에는 흐름 방향 근거가 없다는 뜻이다. 그래서 이 사유는 대부분 '범위 밖·사람 확인'으로 둔다. 화살촉 씨앗만 반영하는 작은 단위는 줄이는 수가 1천 개 남짓이라 뒤로 미룬다(`arrow_probe.py`, `flow_sim.py`).
- **끝점 미연결.** 3c로 매설 배관 점 조각을 정리했다. 남은 12,391개는 다른 원인(점선 끝 여백, 기호에 못 닿은 실선 끝 등)이며 조사 전이다.

## 3. 범위 밖·사람 확인 (초안)

- `not_registered`·`missing_drawing_number`(572): 시험이 등록 없이 추출해서 생긴다. 앱 등록 경로에서는 나오지 않는다.
