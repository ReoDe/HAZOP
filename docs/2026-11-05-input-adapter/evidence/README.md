# 입력 어댑터 증거

> 조사·검증 결과와 작업 상태 판정의 근거를 보관한다.

## 기록 규칙

- 근거마다 조사 일시, 대상 경로 또는 커밋, 확인한 사실, 판정에 미치는 영향을 기록한다.
- 원문 전체를 복사하지 않고 저장소 경로와 필요한 발췌 위치를 연결한다.
- 비밀번호, 토큰, 개인정보 등 민감정보는 기록하지 않는다.
- 증거가 추가되면 아래 인덱스와 [`PROGRESS.md`](../PROGRESS.md)의 관련 상태를 함께 갱신한다.
