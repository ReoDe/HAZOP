## 4. 남은 것·한계

- ④⑤에서 보기 메뉴 "웹 속성 패널 숨기기/보이기"로 패널을 다시 켜면 `#pathq`(오른쪽 아래)가 나타나 넓은 범례와 겹칠 수 있다. 이 상태는 측정하지 않았다.
- 범례가 4줄을 넘으면(캔버스 폭 약 250px 미만) 범례 안에서 스크롤해야 끝 항목이 보인다.
- Qt 쪽 `{"passed": "통과", "blocked": "차단"}` 사본(main_window·analysis·knowledge·register·viewer 화면)은 편집 범위 밖이라 합치지 않았다. 웹 쪽 매핑은 템플릿 한 곳이다.
- ⑤ 1366×768 창에서는 캔버스 아래쪽이 화면 스크롤 영역에 걸려 줌 버튼 일부가 창 밖에 그려진다(고치기 전과 같음, 범례와 무관).
