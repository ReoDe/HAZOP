# 도면 지식화 (2026-11-13)

도면을 믿을 수 있는 지식으로 만들고, 그 위에서 채팅으로 묻고 구간을 다루게 하는 작업 단위 묶음이다. 사용자 결정 2026-11-13(질문 답변 10회와 정리 확인)에 따른다. 의도는 `INTENT.md`, 참고한 제품은 안트로피 AutoPID(<https://antropy.co.kr>)다.

## 첫 성과

가상 도면 한 벌(SNP 표본)에서 추출(AI 검토 포함) → 채팅 질문 → 도면 위 경로 표시가 실제 창에서 돈다.

## 완료 목록

**가. 도면 읽기 품질**

1. 정답지: APR1400 표본 10~15쪽과 가상 도면. AI가 쪽 그림만 보고 작성하고, 사용자가 쪽마다 무작위 20건 안팎을 확인한다.
2. 기호 종류, 태그·번호, 연결, 속성 네 항목의 정확도를 재는 검사.
3. 추출 전 'AI 검토' 토글(구독 연결): 못 읽은 기호의 종류, 태그·속성, 끊긴 연결의 후보 제안과 읽은 결과 다시 확인. 예상 호출 수 표시와 상한, 확신 높은 후보 묶음 수락.
4. 네 항목 모두 95%(최종 목표 100%). '스크립트만'과 '스크립트 + AI 후보' 두 값을 따로 보고한다. 개선이 두 번 이어 1%p 미만이면 멈추고 보고한다.

**나. 채팅 창**

5. AI가 쓰는 그래프 도구 묶음(경로 추적, 상류·하류, 조건 검색, 개수, 도면 표시).
6. 모든 단계 오른쪽의 접을 수 있는 채팅 창. 예시 질문, 빠른 모델 기본, 바꿀 수 있음.
7. 답 카드의 경로 칩과 도면 위 강조, 도면별 목록, 불확실한 곳 경고, '도면·문서에서 확인'과 'AI 일반 지식' 구분.
8. 도면, 설계 문서, HAZOP 결과 질문. 대화는 저장하지 않고, AI가 실행한 일의 기록은 남긴다.
9. 채팅으로 앱 기능 실행. 되돌릴 수 없는 일은 확인을 받는다.

**다. 검토구간**

10. 덮음률 100% 규칙 삭제와 구간 겹침 허용(저장 규격 v2).
11. 도면에서 네모로 끌어 고르고 클릭으로 더하기·빼기 → 구간 만들기.
12. 구간을 누르면 그 구간만 강조.
13. '자동 나누기' 단추 제거. 채팅 요청 → AI가 대표 구간 3~5개를 바로 적용 → 확인 뒤 나머지. 경계는 주요 장비에서 주요 장비까지. 이름과 설계 의도 초안도 AI.
14. 분석을 마친 구간 잠금.

**라. 화면과 배포**

15. 단계 구조 유지, 화면마다 '왼쪽 목록 · 가운데 도면 · 오른쪽 채팅'. 밝은 화면 유지.
16. 내부용 배포본에 구독 연결 포함. 구독 없는 PC는 안내만.

나중: 스캔 이미지, 도면 개정 기록·비교, 전용 단추와 Excel 출력.

## 지킬 것

- **도구 호출의 보안 경계.** 지금 구독 연결은 도구를 하나도 못 쓰게 막아 두었다(`claude_cli.py`). 채팅은 앱이 띄우는 읽기 전용 도구만 열고, 파일·셸 도구는 계속 막는다. 쓰기 동작은 도구가 '제안한 동작'만 돌려주고 앱이 실행한다.
- **AI가 바로 적용한 구간.** `origin: ai`와 미확정 상태를 붙이고, 한 번의 요청은 한 묶음으로 되돌릴 수 있게 한다. 확정본과 잠긴 구간에는 적용하지 않는다. 'AI 결과는 늘 초안'의 예외로 결정로그에 남긴다.
- **정답지의 순환 채점.** 정답지는 추출 결과를 보지 않고 쪽 그림에서만 쓴다. 사용자가 확인할 20건은 무작위로 뽑고 일치율을 기록한다.
- **큰 도면.** 그래프를 통째로 AI에 보내지 않는다. 도구는 결과 상한과 쪽 나누기를 갖추고, 질문당 도구 호출 수에 상한을 둔다.
- **구간 겹침.** 초기사건 인계 묶음에서 같은 (구성요소, 원인)이 두 구간에서 나오면 하나로 묶고 두 구간을 모두 근거로 남긴다.

근거 문서는 `evidence/`에 둔다.
