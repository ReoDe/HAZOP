## 고친 것(자기 파일)

1. **구간 목록·상세가 매번 1초 가까이 걸림**(`api_nodes.py`): 내가 A13에서 더한 도면 범위 표기(`span.annotate`)가 목록·상세를 읽을 때마다 구간 525개를 다시 계산했다(약 0.9초). 프로젝트 그래프 판·구간 집합 판이 같으면 지은 것을 돌려주게 했다. 목록 889 → 120 ms(중앙), 상세 996 → 313 ms.
2. **정리된 보기 쪽을 다시 열 때마다 정돈을 다시 함**(`clean_items.read`): 세 파일 지문과 기호 그림이 같으면 지은 응답을 돌려준다(최대 24쪽). 같은 쪽 다시 열기 577 → 9 ms. 정돈 안의 `deepcopy`도 얕은 사본으로 바꿨다(`clean_layout.py`, 정돈 0.75초 가운데 0.26초가 복사였다).
3. **도면 고치기 저장이 14초**(`api_corrections.py`): ① 태그 겹침 검사가 143쪽 추출 결과를 모두 읽어 수정을 적용했다(`data.tag_conflicts`, 10.8초). 프로젝트 그래프(메모리)에서 찾게 했다. ② 웹 명령은 그래프·지식그래프 다시 만들기를 작업(job)으로 넘기고 바로 답한다(저장은 먼저 끝나 있고, 낡은 그래프 표시가 서 있다가 작업이 끝나면 `changed` 알림). 채팅 길(`apply_edit` 직접 호출)은 그대로 끝까지 기다린다. 시험으로 고정했다.
