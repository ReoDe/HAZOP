# 정답지 독립 두 판의 일치율과 판정 (D-read/R1, 2026-11-13)

APR1400 정답지 12쪽을 두 하위 에이전트(Opus)가 서로 보지 않고 쪽 그림만 보고 따로 썼습니다(A: 첫 판, B: 두 번째 판). 두 판을 위치로 짝지어 견주고, 어긋난 항목은 셋째 에이전트가 그림 조각과 타일만 보고 판정했습니다. 저장소 정답지(`tests/fixtures/read-quality/apr1400/`)는 판정을 반영한 최종본입니다. 절차는 [`docs/specs/extraction.md`](../../../specs/extraction.md#answer-key-procedure) '정답지 절차' 3번입니다.

사용자 표본 확인을 기다리지 않고 이 방식으로 정답지 품질을 지키라는 것은 총괄 지시(2026-11-13, 사용자 지시 전달)에 따른 것입니다. 사용자 확인 목록([answer-key-sample.md](answer-key-sample.md))은 최종본에서 다시 뽑아 두었습니다.

## 방법

- B 판 지침은 A 판 지침에 규칙 몇 가지를 분명히 한 것을 더했습니다. 계기가 낀 연결은 적지 않음, 플랜지·등급 마름모·경계 표시는 기호가 아님, 같은 쪽 안 연결 깃발은 기호가 아님, 유체가 흐르는 일점쇄선은 배관. A 판은 이 점에서 쪽마다 판단이 달랐습니다.
- B에는 A의 영역(`regions`)만 주고 A·기존 정답지·추출 결과는 보지 못하게 했습니다(072쪽 B 작성자는 폴더 목록을 볼 때 008쪽 표본 몇 줄이 화면에 지나갔다고 보고했고, 072쪽과 관계없는 내용이라 그대로 썼습니다).
- 견주기: `python scripts/check_read_quality.py compare <B 폴더> <출력> --crops`. 기호는 채점과 같은 허용 오차(4pt/10pt)로 짝짓습니다. 연결은 계기가 낀 쌍을 뺀 공정 연결만 견줍니다.
- 판정: 어긋난 항목마다 A·B·둘 다 아님 가운데 하나. 연결이 수백 건 갈린 008·105쪽은 쌍을 하나씩 따지지 않고 배관망을 그림에서 한 번 따라가 묶음을 정한 뒤 쌍을 다시 만들었습니다(정한 묶음은 각 정답지의 `limits`에 있음).
- 저장소 밖 근거: `D:\HAZOP-trials\2026-11-13-answer-key\` 아래 `key-b\`(B 판), `compare\`(어긋난 항목과 그림 조각), `final\*-decisions.json`(항목마다 판정과 근거).
