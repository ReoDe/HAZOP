## 안 된 것, 하지 않은 것

- **창을 OS 키보드·마우스로 움직이지 않았다.** 입력은 Qt 이벤트(입력 칸에 글 넣고 Enter, 단추 `click()`)로 넣었고, 실제 창은 `scripts/desktop_lease.py run` 안에서 띄웠다. 키보드·마우스 입력 경로(`verify-hazop`의 `check_user_scenarios.py` 방식)로 같은 시나리오를 다시 도는 일은 남아 있다.
- **① 등록·추출을 화면에서 거치지 않았다.** 등록 화면을 거치지 않고 `install_sample`(추출 + 그래프 만들기)로 준비했다. 등록 화면 시나리오는 R2 단위 몫으로 둔다.
- 상류 질문('~의 상류')은 묻지 않았다. 하류 질문과 같은 도구(`trace_flow`)라고 보고 예산(15회)을 아꼈다.
- 도면 위 표시의 화면 확인은 캡처 한 장씩이다. 칩을 눌러 객체로 이동하는 동작은 시험(`tests/test_chat_panel.py`)으로만 본다.
