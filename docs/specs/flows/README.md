# docs/specs/flows — 단계별 흐름도

제품 규격의 단계 흐름을 그림 문서로 둔다(옛 flow chart/ 폴더).

## 무엇을 넣는가

- 단계 ①~⑤의 흐름도와 전체 흐름(`00-overview.md`). 문서번호 `HZ-FLW-00`~`05`

## 넣지 않는 것

- 흐름을 글로 설명한 규격은 `docs/specs/`의 단계 문서에 둔다.

## 이름 형식

`<번호>-<주제>.md`. 번호는 문서번호의 끝 두 자리와 같게 한다(예: `01-registration.md` = `HZ-FLW-01`).

## 주인

문서는 해당 담당(기획 `hazop-planner`, 디자인 `hazop-designer`, 기록 `hazop-recorder`)이 쓰고, `approved`로 바꾸는 일은 총괄만 한다(HZ-GOV-02 §4.7).

## 폐기 기준

지우지 않는다. 쓰지 않게 된 문서는 `status: obsolete`로 두고, 문서번호는 다시 쓰지 않는다(HZ-GOV-02 §4.6, §4.12).
