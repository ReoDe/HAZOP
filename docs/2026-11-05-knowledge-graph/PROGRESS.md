## 5. 열린 결정

그래프활용 §8.2의 D2~D9는 사용자 위임(2026-11-04)에 따라 **권고안 채택(위임)** 상태로 진행한다. 문서·코드에 반영하기 전에 총괄이 확인한다. 원문·대안은 [그래프활용 §8.2](../../기획서/그래프활용.md#82-남은-결정-권고안-표기)를 따른다. D1은 사용자 확정으로 [`decisions.md`](decisions.md)에 등록되어 있다. 아래 번호는 그래프활용 §8.2의 번호이며, 이 작업의 `decisions.md` ID와 별개다.

|---|---|---|---|
| D2 | 기존 ② 그래프 탭 유지, 이름을 "P&ID 구조"로 변경 | 권고안 채택(위임) | `W6` [추론] |

P1(성능)은 그래프활용 §8.1에 배정이 없어 총괄 판정으로 `W5`(알고리즘 MVP)에 배정했다. 화면 노드 수 상한(그래프활용 §7.3)을 확인하는 검사는 원본에 없으며, `W6` 착수 시 검사 추가 여부를 정한다.

편집 허용 범위 공백: README §8의 허용 경로에는 `W2`(QtWebEngine 확인), `W6`(별도 HTML·vendor·브리지·앱 탭), `W7`(④ 근거 묶음·⑤ 화면)에 필요한 앱·분석 코드 경로와, 그래프활용 D2(② 탭 이름)·D7(신뢰 경계 표)의 문서 반영이 없다. 각 작업 착수 전에 필요한 경로를 결정으로 등록하고 범위를 넓힌다.
