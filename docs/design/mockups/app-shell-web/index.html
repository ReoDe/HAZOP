근거: docs/design/app-shell-web.md. 도면은 SNP 표본 SVG(resources/references/pid-samples), 분석 결과·구간 이름·대화는 예시 값입니다. 네트워크 요청이 없습니다.

지금 → 새

  • 단계 레일(①~⑥)과 단계별 왼쪽 목록 → 왼쪽 얇은 메뉴 5개(도면·구간·분석 결과·초기사건·지식그래프)와 여닫는 패널
  • 도면 연결점 목록·속성 칸·관련 항목 탭(늘 떠 있음) → 구성요소를 누르면 뜨는 말풍선, 채팅 답 카드
  • 모드 단추(분할·편집·경로 질의·층 토글 여러 개) → 도면 아래 도구 막대 하나(이동·네모로 고르기·확대·층)
