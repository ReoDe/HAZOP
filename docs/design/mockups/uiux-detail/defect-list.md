# 현재 앱 디테일 결함 목록 (2026-11-07)

[README](README.md) · [개선 명세](improvement-spec.md) · [조사 요약](survey-summary.md)

## 점검 방법

- 앱: `feat/next-units` 작업 트리(커밋 8041fc5 + 다른 두 세션의 미커밋 변경 포함)를 `scripts/run_app.py --screenshots`로 열어 1366×768·1920×1080 PNG를 찍었다. 표본 데이터는 앱에 들어 있는 kg-SNP-SAMPLE과 SNP-M-101·102다.
- ⑤ 분석 결과는 스크린샷 모드에서 검토구간이 확정되지 않아 빈 상태만 찍힌다. 채워진 화면은 4단계 세션이 남긴 스크린샷(1366·1920, AI 실행 후)을 썼다.
- 근거 표기: **측정**은 스크린샷 픽셀 판독이나 코드 검색으로 확인한 값, **관찰**은 화면에서 본 사실, **[추론]**은 사용 흐름을 짐작한 판단이다.
- 심각도: **높음**은 잘못된 판정이나 작업 차단으로 이어질 수 있음, **중간**은 반복 작업을 느리게 함, **낮음**은 다듬기 수준이다.
- 개선안 번호(U-xx)는 [개선 명세](improvement-spec.md)의 항목이다.

## 이번에 보지 못한 것

- ⑤ 수정 대화상자, Excel 출력, 설정 대화상자는 열지 않았다.
- 실제 대용량 PDF 등록의 진행 상태는 재현하지 않았다. R-6은 위젯이 없다는 관찰과 [추론]이다.
- 다른 두 세션(② 수동 수정, 4단계 API)이 작업 중인 화면은 바뀔 수 있다. 구현 전에 다시 찍어 확인해야 한다.
