# docs/methodology — 방법론 카드

HAZOP·위험도 분석에 쓰는 방법론을 정리한 카드를 둔다(옛 지식/ 폴더).

## 무엇을 넣는가

- 위험도 분석 결합 방법론 같은 방법론 문서. 문서번호 `HZ-MTH-nn`

## 넣지 않는 것

- 지식그래프(앱이 만드는 데이터)는 `work/data/knowledge-graph/`와 `resources/samples/knowledge-graph/`에 있다. 이 폴더와 이름만 비슷하다.
- 제품 규격은 `docs/specs/`에 둔다.

## 이름 형식

`<주제>.md`, 영어 소문자 kebab-case. 문서 머리를 단다.

## 주인

문서는 해당 담당(기획 `hazop-planner`, 디자인 `hazop-designer`, 기록 `hazop-recorder`)이 쓰고, `approved`로 바꾸는 일은 총괄만 한다(HZ-GOV-02 §4.7).

## 폐기 기준

지우지 않는다. 쓰지 않게 된 문서는 `status: obsolete`로 두고, 문서번호는 다시 쓰지 않는다(HZ-GOV-02 §4.6, §4.12).
