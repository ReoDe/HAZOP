## 실행 코드의 접근 방식

resource_path·work_path는 paths 함수를 거친 참조, repo_root는 저장소 루트를 직접 붙인 참조, literal은 행만으로는 알 수 없는 참조(상수 정의, 인자 기본값, 테스트 픽스처 등)다.

| 원본 종류 | literal | repo_root | resource_path | work_path |
|---|---|---|---|---|
| 스크립트 | 55 | 22 | 3 | 9 |
| 코드 | 34 | 0 | 0 | 15 |
| 테스트 | 64 | 30 | 0 | 13 |
| 패키징 | 15 | 0 | 0 | 2 |
