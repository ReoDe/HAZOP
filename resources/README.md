# resources — 읽기 전용 자료

앱과 시험이 읽는 자료를 둔다. 실행 중에는 바꾸지 않는다(옛 자원/ 폴더).

## 무엇을 넣는가

- `library/`: 배포본에 묶는 기준 자료
- `references/`: 참고 자료
- `samples/`: 표본

## 넣지 않는 것

- 사용자 작업 데이터는 `work/`(개발)나 `%LOCALAPPDATA%\HAZOP`(배포본)에 둔다.
- 시험 입력은 `tests/fixtures/`에 둔다.

## 이름 형식

폴더 이름은 영어 소문자 kebab-case다. 도면 번호와 고유명사(`APR1400`, `SNP-M-101`)는 대문자를 쓴다. 폴더 위치는 `hazop/paths.py`의 `FOLDERS`가 정한다.

## 주인

총괄이 승인한다. 기준 자료와 표본은 회귀 점수와 해시에 닿으므로 바꾸면 기준값 규칙(`CLAUDE.md` 규칙 12)을 따른다.

## 폐기 기준

쓰지 않는 자료는 읽는 코드를 먼저 옮기고 지운다.
