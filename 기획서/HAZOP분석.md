# HAZOP 분석 기획

[상세 플로우차트](<../flow chart/04-hazop-analysis.md>) · [정보 통합·관리](정보통합관리.md) · [전체 기획](전체기획.md)

## 목적과 범위

검증된 통합 그래프에서 원인·영향의 후보 경로와 관련 설계정보를 탐색하고, AI가 이를 해석하여 전문가 검토용 HAZOP 초안을 만듭니다. 첫 버전은 사람이 선택한 검토 구간의 정상 운전을 분석합니다. 자동 구간 분할과 기동·정지 모드는 후속 범위입니다.

검토 구간은 여러 설비·배관을 포함하는 HAZOP의 분석 단위이며 그래프의 개별 노드와 구분합니다. 도면 재추출·그래프 수정은 ②·③에 요청하고, 확정 위험도와 최종 검토·조치 관리는 ⑤에서 다룹니다. 현재 문서는 기획 초안으로 분석 코드·DB·화면이 구현되었다는 의미는 아닙니다.

## 질의응답에서 정한 방향

| 항목 | 결정 |
| --- | --- |
| 첫 분석 범위 | 사람이 선택한 검토 구간, 정상 운전 |
| 편차 후보 관리 | 후보를 제시하고 선택·제외·보류 및 판단 이유를 저장. 제외 후보도 재조회·재검토 가능 |
| 알고리즘 역할 | 경로·관련 설계정보 탐색 |
| AI 역할 | 근거 해석, 추가 가설, 위험도 제안. 확인된 정보와 추론·가설 구분 |
| 정보 부족 | 확인 가능한 범위만 분석하고 나머지는 보류·자료 요청으로 기록 |
| 위험도 | ④ AI 제안, ⑤ 사람이 확정 |
| 결과 보관 | DB와 같은 구조화 기록으로 누적하고 나중에 화면으로 다시 표시 |

편차 후보의 초기 생성은 변수·가이드워드와 적용 규칙을 사용하는 방향을 제안합니다. 규칙·초기 변수 목록·자동 제외 기준은 후속 상세 결정 사항이며, 사람이 후보를 추가할 수 있어야 합니다.

## 입력 확인과 분석 준비

- 그래프 버전과 관련 설계자료·조건·원문 근거 버전을 분석 실행에 고정합니다. 최신 자료로 조용히 교체하지 않습니다.
- 검토 구간의 설계 의도, 포함 대상, 경계와 정상 운전모드를 기록합니다. 경계 밖 영향도 필요한 경우 탐색하되 확장 범위를 명시합니다.
- 미확인 조건, 자료 충돌, 방향 미확인 연결을 구분합니다. 그래프 자체가 유효하지 않으면 해당 분석을 보류하고 ③에 보완을 요청합니다.
- 자료 누락은 가능한 분석 전체를 중단하는 사유로 일괄 처리하지 않습니다. 영향받는 편차·판단별로 확인 가능 범위와 부족 자료를 남깁니다.

## 편차 후보와 검토 기록

유량 없음·압력 높음·역류 등의 후보를 제시합니다. 규칙상 비적용으로 분류한 후보도 이번 실행에서 평가한 후보 목록에 남깁니다. 아직 후보 규칙에 포함되지 않은 편차까지 모두 검토했다고 표현하지 않습니다.

| 기록 | 내용 |
| --- | --- |
| 후보 식별 | 후보 ID, 검토 구간, 변수, 가이드워드, 편차 설명 |
| 생성 근거 | 규칙·버전, 관련 설계정보, 자동 제시 또는 수동 추가 여부 |
| 판단 | 선택·제외·보류, 판단 주체·시각·이유 |
| 적용 버전 | 그래프·자료·운전모드·분석 실행 참조 |
| 재검토 | 이전 판단과 새 판단을 별도 이력으로 유지 |

기존 결과를 열면 당시의 전체 후보와 판단을 복원할 수 있어야 합니다. 제외 후보를 다시 선택하거나 보류 항목을 재개할 수 있습니다. 자료나 그래프가 바뀌면 이전 판단을 자동 승인으로 복사하지 않고 재검토 대상을 표시합니다.

## 그래프 알고리즘의 역할

Python에서 편차와 대상에 맞는 탐색 규칙을 적용합니다. 최초에는 관계 종류·방향·범위를 제한한 도달성 탐색(BFS/DFS 등)을 검토하고, 공정별 규칙은 실제 사례로 검증합니다. 구체적인 알고리즘과 임계값은 아직 확정하지 않습니다.

| 탐색 | 고려할 정보 |
| --- | --- |
| 원인 후보 범위 | 상류·하류, 밸브·펌프 상태, 유틸리티 의존, 제어 동작 등의 관련 대상 |
| 영향 후보 범위 | 편차가 영향을 줄 수 있는 연결 대상, 분기, 경계와 외부 시스템 |
| 보호수단 | 해당 편차·대상과 연결된 경보·인터록·압력 방출 및 관련 조건 |
| 근거 묶음 | 경로의 노드·관계 ID, 설계조건, 물질·사양·제어 정보와 원문 위치 |

물리 배관, 신호, 제어, 보호 관계를 구분하고 탐색 방향을 기록합니다. 순환 그래프는 방문 상태·깊이·경로 수 제한으로 처리하며, 탐색이 제한되거나 잘린 사실도 결과에 남깁니다. 단일 최단 경로만으로 모든 원인·영향을 포괄했다고 판단하지 않습니다.

연결상 도달 가능하다는 사실은 인과관계나 실제 전파를 입증하지 않습니다. 정상 유동 방향만으로 역류·과압 전파 가능성을 일괄 배제하지 않으며, 상태·조건에 따른 검토가 필요합니다. 보호수단이 그래프에 있다는 이유만으로 독립성·용량·작동 적정성을 확정하지 않습니다.

## AI 추론과 위험도 제안

AI에 편차, 설계 의도·정상 조건, 알고리즘이 찾은 경로와 원문 근거, 누락 정보와 탐색 한계를 전달합니다. 원인·결과·보호수단의 해석과 추가 가설을 구분해 반환하도록 합니다. 추가 가설은 검증된 그래프의 사실로 자동 등록하지 않습니다.

위험도 제안에는 프로젝트에서 정한 심각도·가능성 등급과 위험도 기준표를 적용합니다. AI는 등급과 설명을 제안하고 Python은 허용값·기준표 대응을 검사·계산합니다. 기준표가 점수 곱 방식이 아닌 경우 해당 표의 규칙을 따릅니다.

- 위험도 제안마다 적용 기준·버전, 평가한 시나리오, 심각도·가능성 근거, 가정·불확실성을 기록합니다.
- 보호수단 반영 전·후 등 평가 기준을 명시합니다. 보호 기능이 미확인이면 위험 감소 효과를 확정적으로 반영하지 않습니다.
- 기준표나 판단 근거가 없으면 등급을 임의 생성하지 않고 위험도 제안을 보류합니다. 확인 가능한 원인·결과 초안은 유지합니다.
- AI 제안 위험도와 ⑤의 사람이 확정한 위험도는 별도 필드로 남깁니다. 제안을 확정값으로 표시하지 않습니다.
- AI 결과의 참조·허용값 검증은 가능하지만 추론의 공학적 타당성은 전문가 검토가 필요합니다.

## 정보 부족과 결과 저장

원인·결과·보호수단·위험도 각각의 확인 상태를 관리합니다. 보호수단 자료가 없으면 '없음'이 아니라 '미확인'으로 둡니다. 부족 자료, 요청 이유, 영향을 받는 후보·판단을 연결합니다.

| 저장 단위 | 주요 내용 |
| --- | --- |
| 분석 실행 | 실행 ID, 구간, 정상 운전 조건, 그래프·자료·규칙 버전, 탐색 설정 |
| 편차 후보·판단 이력 | 전체 제시 목록, 선택·제외·보류, 주체·이유·이전 판단 |
| 시나리오·근거 | 원인·결과·보호수단, 경로 참조, 원문 위치, 사실/해석/추가 가설 구분 |
| 위험도 제안 | AI 제안 등급·근거·가정, 기준표 버전, 계산 결과·제안 상태 |
| 보류·자료 요청 | 부족 항목, 판단 불가 범위, 요청 자료, 재검토 상태 |
| AI 실행 기록 | 사용 모델·요청 템플릿·입력 근거 묶음·응답·실행 시각과 검증 결과 |

DB 제품은 아직 선택하지 않습니다. 논리적인 ID와 참조를 먼저 정하고, 저장된 기록만으로 당시 화면을 다시 구성할 수 있게 합니다. 생성 기록은 ④에서 남기고, 장기 조회·전문가 확정·조치 추적은 ⑤에 연결합니다. AI가 실패해도 후보·탐색 결과는 보존하고 실패한 추론 단계부터 재시도할 수 있어야 합니다.

## 독립 검증

다른 단계가 미구현이어도 샘플 통합 그래프·설계정보·편차 규칙·평가 기준표로 검증할 수 있어야 합니다. 알고리즘과 저장·상태 검증은 고정된 AI 응답 샘플로 수행할 수 있으며, 실제 AI 추론의 품질 평가는 전문가가 별도 수행합니다.

| 사례 | 기대 결과 |
| --- | --- |
| 정상 운전의 선택 구간 입력 | 범위·모드·설계 의도와 입력 버전 고정 |
| 후보 선택·제외·보류 후 재조회 | 전체 목록·판단 이유·이력 복원, 재선택 가능 |
| 분기·순환·경계 밖 연결 포함 | 탐색 종료 보장, 관계 종류·경계·제한 이력 표시 |
| 도달 가능한 경로만 있고 인과 근거 부족 | 연결 경로와 원인 가설을 구분, 확정 사실로 표현하지 않음 |
| 운전조건·물질 또는 보호수단 자료 부족 | 가능 범위만 초안 생성, 관련 판단 보류·자료 요청 |
| AI가 존재하지 않는 노드·근거를 인용 | 참조 오류 검출, 검증된 근거로 통과 금지 |
| 기준표 없는 위험도 요청 | 위험도 제안 보류, 임의 등급 생성 금지 |
| AI 등급과 기준표 결과 불일치 | Python이 불일치 검출·계산, AI 확정값으로 저장 금지 |
| 보호수단 작동 조건 미확인 | 보호 효과를 확정적으로 반영하지 않음 |
| AI 실패 또는 재분석 | 후보·탐색 결과와 이전 실행 보존, 별도 실행·버전 추적 |

### 통과와 보류 기준

전체 후보의 판단 상태, 그래프·원문 참조, 탐색 범위와 한계, 가설 표시, 보류 사유가 유효해야 합니다. 위험도 제안은 정의된 평가 기준에 맞고 제안임이 표시되어야 합니다. 해결되지 않은 참조·형식 오류는 전문가 전달본에서 정상 결과로 취급하지 않습니다. 보류 항목은 별도 상태로 함께 전달할 수 있습니다.

자동 검증 통과는 전문가 승인이나 분석의 완전성을 뜻하지 않습니다. 그래프 탐색의 정확성과 AI 해석의 품질을 따로 평가합니다.

## 다음 기획

⑤ 검토·결과 관리에서 저장 결과의 재조회 화면, 전문가의 판단·위험도 확정, 조치·이력 관리를 구체화합니다. 편차 규칙 목록, 위험도 기준표와 그래프 탐색 한계의 구체값은 구현 전 실제 샘플에 맞춰 정합니다.
