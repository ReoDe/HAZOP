# hazop/study — 검토구간과 AI 연결

`hazop` 패키지의 하위 패키지다.

## 무엇을 넣는가

- 검토구간 분할·이전, AI 연결(API 키·Claude CLI·HTTP), 구간별 결과 저장

## 넣지 않는 것

- 분석 로직은 `hazop/analysis/`에 둔다.
- 시험은 `tests/`에 둔다.

## 이름 형식

`<모듈>.py`(소문자, 밑줄). 패키지마다 `__init__.py`가 있다.

## 주인

구현 담당(`hazop-developer`)이 고치고, 검토 담당(`hazop-reviewer`)의 검토와 시험·검사 통과를 거쳐 총괄이 커밋한다.

## 폐기 기준

쓰지 않는 코드는 호출하는 곳을 모두 옮긴 뒤 같은 커밋에서 지운다.
