# hazop/kg — 지식그래프

`hazop` 패키지의 하위 패키지다.

## 무엇을 넣는가

- 지식그래프 스키마, 자동 생성, 문서에서 주장 뽑기, 화면 템플릿, 제3자 라이브러리(`vendor/`)

## 넣지 않는 것

- `vendor/`는 SHA-256으로 고정된 가져온 파일이라 고치지 않는다.
- 시험은 `tests/`에 둔다.

## 이름 형식

`<모듈>.py`(소문자, 밑줄). 패키지마다 `__init__.py`가 있다.

## 주인

구현 담당(`hazop-developer`)이 고치고, 검토 담당(`hazop-reviewer`)의 검토와 시험·검사 통과를 거쳐 총괄이 커밋한다.

## 폐기 기준

쓰지 않는 코드는 호출하는 곳을 모두 옮긴 뒤 같은 커밋에서 지운다.
